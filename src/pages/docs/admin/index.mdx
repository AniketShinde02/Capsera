# Admin Panel Guide

This section is for Capsera administrators. It details how to manage users, content, and system health.

## Accessing the Admin Panel
Navigate to `/admin` or click "Admin Dashboard" in the user menu. Only users with the `admin` role can access this area.

## Key Features
- **User Management:** View, ban, or promote users.
- **Content Moderation:** Review flagged images and captions.
- **Analytics:** View real-time generation stats.

> **Warning:** Actions taken in the Admin Panel (like banning a user) are immediate and often irreversible. Proceed with caution.
