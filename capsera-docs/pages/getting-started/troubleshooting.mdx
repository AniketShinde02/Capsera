# Troubleshooting

<Callout type="error" emoji="️🚫">
  **Common Issue:** "Image upload failed"
</Callout>

If your image upload fails, check the following:
1. Is the file size under **10MB**?
2. Is the format **JPEG, PNG, or WebP**?
3. Are you using a VPN? (Sometimes VPNs block our upload endpoint).

<Callout type="info" emoji="ℹ️">
  **Pro Tip:** If the AI generates nonsense, try cropping the image to focus on the main subject.
</Callout>
