# How to Contribute

We welcome contributions to Capsera's documentation.

## Editing a Page
Click the **"Edit this page on GitHub"** link at the right sidebar of any page to open a PR.

## Adding a New Guide
1. Create a new `.mdx` file in `pages/guides/`.
2. Add it to `_meta.json`.
3. Follow the [MDX](https://mdxjs.com/) syntax.

## Guidelines
- Keep it simple.
- Use screenshots.
- Be nice.
