# 🤖 Google Forms AI Prompt for Capsera Feedback Form (Under 5000 Characters)

## Copy this prompt and paste it into Google Forms AI:

```
Create a feedback form for "Capsera" - an AI caption generation app. Title: "Capsera Feedback Survey". Description: "Help us improve Capsera! Your feedback helps us create better AI caption experiences."

**REQUIRED QUESTIONS:**
1. Name (Short answer, Required)
2. Email (Short answer, Required, Email validation)
3. How often do you use Capsera? (Multiple choice: Daily, Weekly, Monthly, First time, Occasionally)
4. What do you use Capsera for? (Multiple choice: Social media, Business, Personal, Education, Creative, Other)
5. Feedback type (Multiple choice: Bug report, Feature request, General feedback, Performance issue, UI/UX, Other)
6. Overall satisfaction (Linear scale 1-10: Very dissatisfied to Very satisfied)
7. Caption quality rating (Linear scale 1-10: Poor to Excellent)
8. Speed rating (Linear scale 1-10: Very slow to Very fast)
9. What do you like most? (Paragraph, Required)
10. What challenges have you faced? (Paragraph, Required)
11. What features would you like added? (Paragraph, Required)
12. Have you used other AI caption tools? (Multiple choice: Yes tried others, No first time, Prefer Capsera, Prefer others)
13. Personal or business use? (Multiple choice: Personal, Business, Both)
14. Willing to pay for premium? (Multiple choice: $0-5/month, $6-10/month, $11-20/month, $21-30/month, $31-50/month, $50+/month, Prefer free)
15. Premium features wanted? (Multiple choice: Unlimited generations, Priority processing, Customization, Team collaboration, API access, Bulk processing, Analytics)
16. Recommend Capsera? (Multiple choice: Definitely, Probably, Maybe, Probably not, Definitely not)
17. Browser/Device info (Short answer, Optional)
18. Additional comments (Paragraph, Optional)

**FORM SETTINGS:**
- Collect emails: Yes
- Progress bar: Yes
- Blue/white theme
- Mobile-friendly
- Thank you: "Thank you! We'll review your feedback within 24-48 hours."
- Create Google Sheet for responses
- Enable email notifications
```
